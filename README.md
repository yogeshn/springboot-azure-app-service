# springboot-azure-app-service
Sample Hello world springboot application to deploy on Azure App Service

## Requirements
- Java 21
- Maven 3.9+
- Spring Boot 3.3.3

## Build
```bash
mvn clean package
```

## Test
```bash
mvn test
```

## Run
```bash
java -jar target/springboot-azure-app-service-0.0.1-SNAPSHOT.jar
```
